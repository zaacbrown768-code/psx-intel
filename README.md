# PSX INTEL — AI Wealth Coach

One file. No server. No installation. Works on any device.

## How to use

### Option A — Open locally (simplest)
1. Download `index.html`
2. Double-click to open in Chrome
3. Enter your Anthropic API key

### Option B — GitHub Pages (permanent free URL)

1. Create a GitHub account at github.com
2. New repository → name it `psx-intel` → Public
3. Upload `index.html` → rename it to `index.html` if needed
4. Go to: Settings → Pages → Source: Deploy from branch → Branch: main → / (root) → Save
5. Your app is live at: `https://your-username.github.io/psx-intel`

### Get your free Anthropic API key
1. Go to console.anthropic.com
2. Sign up free
3. API Keys → Create Key
4. Copy and paste into the app

## Features
- Full FA + TA + ICT/Smart Money analysis
- Real-time PSX data via web search
- Complete trade plans: entry, SL, 3 targets, R:R ratio
- Weekly watchlist scanner
- Market structure analysis
- Compounding roadmap
- Pakistan macro dashboard

## Security
Your API key is stored only in your browser (localStorage). Never sent anywhere except Anthropic's servers.
